# UI audit v1.4: v1.3.0 against the v1.4.0 OSINT console

Generated by `scripts/audit/ui_audit_v14.py` from `test/ui_audit.mjs` metrics. Both builds were measured with the same checks at 1280x800, 1920x1080 and 3840x2160 (Playwright, SwiftShader, DPR 1, axe-core 4.11 WCAG 2.0 / 2.1 / 2.2 A + AA). Review findings come from a heuristic and ergonomic review of v1.3 against the OSINT-console brief, plus a second review of the v1.4 beta (the polish pass, `review (polish)` rows); see [ADR 0004](../adr/0004-osint-console-information-architecture.md) and the [wireframes](../design/wireframes/README.md).

Every finding has exactly one label:

| Label    | Meaning here                                                                     |
| -------- | -------------------------------------------------------------------------------- |
| bug      | the layout is broken: overlap, clipping, a view that cannot open                 |
| error    | a rule is violated: an axe / WCAG failure, or two sources of truth that disagree |
| issue    | works, but below the house standard (sizes, missing cue, colour-only encoding)   |
| problem  | a missing capability that the analyst workflow needs                             |
| dilemma  | a trade-off with no free answer; the decision taken is recorded                  |
| conflict | two rules or conventions collide; the resolution is recorded                     |
