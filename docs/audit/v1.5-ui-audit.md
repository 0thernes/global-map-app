# v1.5 UI audit: v1.4.0 → v1.5.0

Generated by `scripts/audit/ui_audit_v15.py` from `test/ui_audit.mjs` metrics (Playwright, SwiftShader, DPR 1, axe-core 4.11 WCAG 2.0 / 2.1 / 2.2 A + AA) at 1280x800, 1920x1080 and 3840x2160. v1.4.0 was captured from a v1.4.0 worktree with the v1.5 view list, so both columns show the same camera and the same view. Review findings come from the v1.5 review of the globe, visuals, ergonomics and system design against the owner's brief; see [ADR 0005](../adr/0005-globe-visual-system.md) and the [wireframes](../design/wireframes/README.md). Every finding has exactly one label: bug, error, issue, problem, dilemma or conflict.

## Summary

- **28 findings**: 2 error, 15 issue, 5 problem, 4 dilemma, 2 conflict.
- **Status:** 23 fixed, 5 decided.
- Open bugs or errors: 0.
