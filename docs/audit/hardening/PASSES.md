# Hardening pass catalogue

Generated by `python3 scripts/audit/hardening_passes.py` from the registry in that script. Each pass is one lens applied to one scope. **auto** passes are executed by the script (raw output: [passes_run.json](passes_run.json)); **manual** passes are line-by-line reviews whose record is the note below and the rows in [findings.csv](findings.csv).

**127 distinct passes** (71 auto, 56 manual). The request asked for up to 200; this catalogue counts only passes that were actually defined and executed, and does not pad the number by re-running the same lens.
