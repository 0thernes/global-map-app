# Data dictionary

Every column in the case export (**Export › CSV / GeoJSON**, `COMMON` in `src/app_core.js` and `data/build_data.py`),
then the derived fields the build adds. Blank means the source did not say; the build never fills a value in.
Rules for grades, pins and circles are in [data-and-grading.md](data-and-grading.md); the known biases are in
[limitations.md](limitations.md).

## Export columns (in order)

| Column                     | Type                                                                | Meaning                                                                                                                                                                                          |
| -------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`                       | text                                                                | Stable record id from the source (`GEIPAN-1811`, `PDF7-G12.8.1.1`); a `~layer` suffix marks a repeated id from a second file.                                                                    |
| `name`                     | text                                                                | Record title as published.                                                                                                                                                                       |
| `date`                     | ISO 8601                                                            | Event date, `YYYY-MM-DD`. Negative years are BCE in astronomical numbering (`-0011` = 12 BCE). Year- or month-precision dates are stored on the 1st; read `date_precision`.                      |
| `date_precision`           | `day` · `month` · `year` · `decade`                                 | How much of `date` the source gives. Never finer than the date itself: an impossible source date (`2000-09-31`) is kept to the month and explained in `date_note`.                               |
| `date_low`, `date_high`    | ISO 8601                                                            | Range the event falls in, drawn as a range bar. A decade (`198-`) becomes a ten-year range.                                                                                                      |
| `date_disputed`            | text                                                                | The competing dates and who gives each, when sources disagree.                                                                                                                                   |
| `lat`, `lon`               | decimal degrees (WGS 84)                                            | Coordinate as published, rounded to 6 decimals (about 0.1 m). Never jittered.                                                                                                                    |
| `coord_precision`          | `exact_site` · `within_1km` · `locality` · `region` · `unspecified` | How exact the coordinate is. Only `exact_site` and `within_1km` are drawn as pins; the rest are circles.                                                                                         |
| `coord_source`             | text                                                                | Where the coordinate came from (e.g. `geo.api.gouv.fr commune centre: Bacouël (INSEE 60039)`). Shown on every dossier.                                                                           |
| `continent`                | text                                                                | Natural Earth continent, from the source or the point-in-polygon lookup.                                                                                                                         |
| `country_iso`              | ISO 3166-1 alpha-2                                                  | From the source, else Natural Earth `ISO_A2_EH` at the point.                                                                                                                                    |
| `country`                  | text                                                                | Country name; `Ocean/International waters` when the point is on no country.                                                                                                                      |
| `admin1`, `admin2`         | text                                                                | First- and second-level subdivision as published (French région/département for GEIPAN).                                                                                                         |
| `locality`                 | text                                                                | Town or place name as published.                                                                                                                                                                 |
| `postal_code`              | text                                                                | Postal code as published. French codes are 5 digits; a leading zero lost to a spreadsheet (`8430.0`) is restored (`08430`).                                                                      |
| `urban_rural`              | text                                                                | Setting at the point, with the rule in the value: inside a Natural Earth 10m urban area, or the distance to the nearest GeoNames city of 15 000+ people.                                         |
| `category`                 | text                                                                | App category (`UAP case`, `Abduction`, `Missing person`, …). The source's own label is kept in `category_raw` when it differs.                                                                   |
| `subtype`                  | text                                                                | Finer class from the source (e.g. `GEIPAN class B`).                                                                                                                                             |
| `count`                    | integer                                                             | Number of objects or events the source reports.                                                                                                                                                  |
| `summary`                  | text                                                                | Short description as published (GEIPAN summaries are in French).                                                                                                                                 |
| `source_title`             | text                                                                | Title of the cited source.                                                                                                                                                                       |
| `source_url`               | URL                                                                 | The citation. Every plotted row has one.                                                                                                                                                         |
| `source_type`              | text                                                                | Kind of source (government archive, encyclopedia, press, …).                                                                                                                                     |
| `dataset`                  | text                                                                | Dataset the row came from. Rows from a CSV without this column are labelled with their file, e.g. `local CSV qwm_uap_cases.csv (from qwm/wiw/hs_candidates.csv)`.                                |
| `grade`                    | text                                                                | Evidence grade; see [data-and-grading.md](data-and-grading.md#grades).                                                                                                                           |
| `witness_count`            | integer                                                             | Number of witnesses the source reports.                                                                                                                                                          |
| `nearest_military_site_km` | km                                                                  | Great-circle distance (R = 6371 km) to the nearest military site in `data/layers/military.js`, forts and gendarmerie excluded. The QWM value, if any, is kept in `qwm_nearest_military_site_km`. |
| `nearest_nuclear_site_km`  | km                                                                  | Distance to the nearest nuclear site as published by QWM.                                                                                                                                        |
| `linked_case`              | ids                                                                 | Other record ids the source links to this one (the app splits on `;`, `                                                                                                                          | `, `,` or spaces). |
| `notes`                    | text                                                                | Source notes, including `[verify]` markers.                                                                                                                                                      |

The CSV is RFC 4180 (CRLF rows, quoted fields) and text cells that start with `=`, `+`, `-`, `@`, tab or CR get a
leading `'` so spreadsheets do not run them as formulas; numbers and BCE dates are exempt.

## Fields the build adds

| Field                                                                                   | Meaning                                                                                                                                                              |
| --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `coord_radius_km`                                                                       | Circle radius: the source's own radius, else one stated in `notes` (`coord_radius_source = notes`), else the default for `coord_precision` (0.1, 1, 10, 100, 25 km). |
| `date_note`                                                                             | Why `date_precision` is coarser than the source column said.                                                                                                         |
| `decade`, `century`                                                                     | Grouping labels. Before 1000 CE `decade` holds the century (`700s`); BCE rows use millennium (`decade`) and century (`century`) buckets.                             |
| `country_display`                                                                       | Country, or `Space` / `Antarctica` / `Ocean/International waters`.                                                                                                   |
| `shore_km`, `over_water`                                                                | Distance to the nearest coast or lake shore (Natural Earth 10m), and the water body when the point is on water.                                                      |
| `same_as`, `conflicts`                                                                  | Records judged to be the same event, and every field where they disagree, each value with its source. No winner is picked.                                           |
| `nearest_military_site`, `nearest_military_site_source`, `nearest_military_site_method` | Name, citation and method of the nearest military site.                                                                                                              |
| `verify`                                                                                | Citations QWM flagged with `[verify]`.                                                                                                                               |
| `pdf7_ref`                                                                              | The PDF 7 section and page the row is linked to.                                                                                                                     |
| `layer`, `file`                                                                         | Layer id and the source file the row was read from.                                                                                                                  |
| `grade_raw`, `category_raw`                                                             | The published value when the build collapsed or mapped it.                                                                                                           |
