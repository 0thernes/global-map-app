# Support

- **Questions and ideas:** open a [discussion](https://github.com/0thernes/global-map-app/discussions) or an issue
  with the _feature request_ template.
- **Bugs:** use the _bug report_ template. Include the browser, the URL (with parameters) and what the console says.
- **A case, site or dataset to add:** use the _data source / new case_ template. A source URL and a grade are required.
- **Security problems:** see [SECURITY.md](SECURITY.md); please do not file them publicly.
- **Everything else:** 0_0@0thernes.art · [0thernes.art](https://0thernes.art) · [@0thernes_ai on X](https://x.com/0thernes_ai)

This is a small project maintained by 0thernes L.L.C. Replies are best effort.
