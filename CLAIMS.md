# Claims ledger

Every verifiable engineering, data-provenance, security, and accessibility claim made by
`global-map-app` maps to the command and test that checks it and the observation that would prove
it wrong. No row, no claim. (Build Standard v1.2.0: B04, B05, B42.)

## Scope note

Global Map plots **sourced historical and archival reports** alongside reference geographic layers
and computes observational distance/permutation statistics with explicit caveats. It does **not**
verify witness claims, assert physical causes for UAP reports, or claim to solve any open scientific
problem.

## What would prove us wrong (Falsification)

Any of the following observations falsifies a claim above (Build Standard B42):

1. `npm test`, `npm run lint`, `npm run test:data`, `npm run test:py`, or `npm run build && git diff --exit-code -- js/app.js` exits non-zero on a clean checkout (`C01`–`C05`).
2. `data/cases.js` contains a row lacking an `http(s)` `source_url`, missing `coord_source`, using coordinate jitter, or leaking `NUFORC` rows into public tracked files (`C03`).
3. Network inspection during `npm run test:smoke` records any request to Cesium ion or any API-key-gated endpoint (`C06`).
4. `npm run test:a11y` reports any WCAG 2.2 A/AA violation or `npm run test:perf` exceeds the 20 frames / 10 s idle budget (`C07`).
5. Independent statistical review shows that a reported observational proximity pattern disappears after correcting for population density, coastline, or reporting-archive bias (already flagged as a threat to validity in `LIMITATIONS.md` and `docs/limitations.md` — this app makes no causal claim).
